# ziweiwu/homebrew-tap

Homebrew formulae for my tools.

```sh
brew tap ziweiwu/tap
brew install useful-system-monitor
```

## useful-system-monitor

See what's using up your machine, and close what's hogging it. CPU, memory,
disk and battery at a glance, in the terminal.

Source and issues: https://github.com/ziweiwu/useful-system-monitor

The formula ships the prebuilt binary from that repository's GitHub Release
rather than compiling from source, so installing does not pull a Rust toolchain
onto your machine.
